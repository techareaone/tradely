Features

Stock trading minigames – Price guessing, portfolio races, daily market puzzles.

Live activity feed – Broadcasts every play, score, and record to a channel you choose.

Server ranking – Only invited servers appear in the public server list.

One command

Use /setchannel #channel to pick a text channel. The bot will then post:

  • Player finished a game with score
  • Updated leaderboard snapshots
  • Weekly server ranking changes
